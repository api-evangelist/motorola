# Motorola

> Motorola (motorola.com) is the consumer mobile-device brand — Android smartphones (moto g, moto edge, razr), tablets, and accessories — operated by Motorola Mobility, a Lenovo company. This profile is maintained in the API Evangelist network. As of this pass Motorola publishes no open public REST/HTTP API developer portal on the consumer domain; the historical developer.motorola.com (Moto Mods hardware SDK for the Moto Z) is no longer reachable. Enterprise/public-safety APIs are offered separately by Motorola Solutions (docs.motorolasolutions.com), a distinct company, under a gated partner developer program.
